# Banner Assets

Upload assets here for the Agent Marketing Banner generator.

## Folders

### /logos/
Place telecom logo images here:
- `mtn.png` — MTN logo (recommended: 200x200 PNG with transparent background)
- `telecel.png` — Telecel logo
- `airteltigo.png` — AirtelTigo logo

### /heroes/
Place hero images (people holding phones, smiling, modern Ghana vibe):
- `hero-1.jpg` — First hero image (recommended: 600x800 or larger, portrait orientation)
- `hero-2.jpg` — Second hero image
- Add as many as needed with sequential naming.

### /overlays/
Optional decorative overlay PNGs (data icons, patterns, etc.)

## Fallback Behavior
- If logos are missing, the banner generator uses styled text chips instead.
- If hero images are missing, banners use the "Clean Modern" layout (no person).
